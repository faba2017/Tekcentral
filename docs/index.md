# Documentation Index

## Sections

- `docs/suppliers/`: supplier status and capability notes.
- `docs/features/`: planned platform feature notes.
- `docs/architecture/`: integration and technical architecture notes.

## Status Labels

- `CONFIRMED`: Supported by the current codebase or explicit requirements.
- `PLANNED`: Intended future direction, not implemented yet.
- `PENDING CONFIRMATION`: Unknown until supplier, business, legal, payment, tax, or technical details are confirmed.
- `UNDECIDED`: A product or technical decision has not been made.
