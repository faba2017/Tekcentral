# Cart

## CONFIRMED

- Phase 3 implements a frontend-only demo cart.
- Cart state persists to localStorage.
- The cart supports add, remove, quantity change, item count and subtotal.
- The `/cart` page links to a safe `/checkout` placeholder and does not process payment or create orders.

## PLANNED

The cart may support B2C purchases and future solution-package flows.

## PENDING CONFIRMATION

- Guest checkout
- Account checkout
- VAT handling
- Stock reservation
- Supplier offer selection
- Quote-to-cart behaviour
