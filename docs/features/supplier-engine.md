# Supplier Engine

## CONFIRMED

- No supplier engine is implemented yet.
- Supplier independence is required.

## PLANNED

The supplier engine should eventually use supplier adapters and normalized supplier offers.

Supplier selection may consider:

- Availability
- Cost
- Delivery time
- Location
- Fulfilment capability
- Reliability
- Warranty arrangements
- Margin

## PENDING CONFIRMATION

- Stock refresh cadence
